# 🕷️ SPV | SpiderV2Ray

اتصال امن، پایدار و سریع به اینترنت — ساده برای همه، قدرتمند برای حرفه‌ای‌ها 🚀

## ✨ ویژگی‌ها

### 🎁 ۵ گیگ رایگان
بدون نیاز به ثبت‌نام، شماره موبایل یا کارت بانکی، همین با نصب برنامه
۵ گیگ سرویس رایگان با زمان نامحدود فعال می‌شود.

### 🔌 پشتیبانی از پروتکل‌ها
- VLESS
- VMess
- Trojan
- Shadowsocks

### 📥 افزودن کانفیگ به ۴ روش
- 🔗 لینک مستقیم
- 📡 لینک Subscription (با بروزرسانی خودکار گروه)
- 📷 اسکن QR Code (دوربین یا انتخاب از گالری)
- 📁 فایل اختصاصی `.spvt`

### ⚡ امکانات
- نمایش لحظه‌ای مصرف اینترنت (آپلود/دانلود)
- تست پینگ سرورها (تکی یا گروهی)
- نمایش موقعیت اتصال فعلی
- **LAN Bypass**: ترافیک شبکه محلی از تونل رد نمی‌شود
- **Split Tunneling**: خروج اپ‌های دلخواه از مسیر فیلترشکن
- بک‌آپ و بازیابی کامل تنظیمات
- ویجت اتصال روی صفحه اصلی گوشی
- تم روشن و تاریک
- بدون تبلیغات مزاحم

### 🤝 اشتراک‌گذاری با فایل .spvt
هر کاربر می‌تواند کانفیگ خودش را همراه با نام و آیدی کانال تلگرامش
در قالب یک فایل `.spvt` به اشتراک بگذارد. هر کسی که این فایل را
ایمپورت کند و به همان سرور وصل شود، دکمه‌ای برای دسترسی به کانال
سازنده در صفحه اصلی می‌بیند.
